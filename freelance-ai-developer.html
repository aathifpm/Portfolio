Live Demo Source Code

Users upload complex documents, the system chunks and embeds them into a vector store, retrieves relevant passages, and generates source-attributed answers using a RAG pipeline.

The Problem

General LLMs hallucinate when asked about internal documents. Needed strict passage retrieval with exact source citations.

Engineering Highlights

  • Document parsing & semantic chunking
  • FAISS vector index & sentence-transformers
  • LangChain QA retrieval pipeline
  • Gemini Pro synthesis with citation enforcement
  • Conversational memory management

Project Result

Open-source tool for document search and citation-backed Q&A.

Self-Reported Benchmark: ~21 ms average retrieval latency
